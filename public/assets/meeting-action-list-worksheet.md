# Meeting action-list worksheet

From AIViewer's lesson "Turn Meeting Notes into an Action List Without Inventing Deadlines":
https://aiviewer.ai/guides/meeting-notes-to-action-list-with-ai/

Use this sheet to check an action list (written by you or by an AI assistant) against the meeting notes before you send it.

## 1. Sort every item

| Item | Decision, action or open question? | Owner stated in notes? | Date stated in notes? | Condition or uncertainty | Source line | Confirmed with owner? |
|---|---|---|---|---|---|---|
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |
| | | | | | | |

Write "not stated" when the notes do not name an owner or a date. Do not fill the gap with a guess.

## 2. Check before sending

- [ ] Every owner can be traced to a sentence where that person agreed or was asked.
- [ ] Every date can be traced to a sentence, or is marked as tentative or as my interpretation.
- [ ] Words such as "probably", "maybe" and "once X happens" stay attached to their task.
- [ ] Suggestions ("someone should", "we could") are open questions until someone agrees.
- [ ] Nobody absent from the meeting has been given a task without being asked.
- [ ] Decisions are listed as decisions, separately from tasks.
- [ ] Items with no owner are flagged as needing one.

## 3. Confirm

Send the list as a short message that names each person next to their task and asks them to correct anything wrong. Checking the list against the notes shows it matches the notes; only the people involved can confirm the notes were right.
