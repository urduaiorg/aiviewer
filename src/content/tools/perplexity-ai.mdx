## Frequently Asked Questions

### Is Perplexity AI free?
Yes, Perplexity offers a powerful free search engine that uses standard AI models. The Pro version ($20/mo) unlocks advanced models like GPT-5.4 and Claude Sonnet 4.6, plus unlimited file uploads.

### Does Perplexity hallucinate?
Because Perplexity grounds its answers in real-time web search results (RAG - Retrieval-Augmented Generation), it hallucinates far less than standard chatbots. However, if it reads a low-quality or incorrect source website, it may repeat that incorrect information.

### Is Perplexity a search engine or a chatbot?
It is primarily an answer engine. While it has a conversational interface, its core purpose is to replace Google Search by giving you direct answers with citations rather than a list of blue links.

### Can Perplexity read PDFs?
Yes, you can upload PDFs and ask Perplexity to summarize or query them. The Pro tier offers much higher limits for file uploads.
