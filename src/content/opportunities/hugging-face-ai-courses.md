## What You'll Learn

Hugging Face offers 11 comprehensive, open-source AI courses — all free:

| Course | Focus |
|---|---|

| **NLP Course** | Transformers, tokenization, fine-tuning |
| **Deep RL Course** | Reinforcement learning from scratch |
| **Diffusion Models Course** | Image generation, stable diffusion |
| **ML for Games** | AI-powered game development |
| **Audio Course** | Speech recognition, text-to-speech |
| **Computer Vision Course** | Image classification, object detection |
| **ML for 3D** | 3D representations and neural rendering |
| **Robotics Course** | Embodied AI and robot learning |

| **Ethics & Society** | Responsible AI development |

## Who It's For

- Developers who want to go deep on open-source AI tools
- Researchers building on top of the Hugging Face ecosystem (Transformers, Datasets, Spaces)
- Practitioners who want a verifiable certificate without paying for a course platform
- Anyone who learns best through doing — all courses involve code and Hugging Face Spaces

## How to Earn a Certificate

For courses with active certification (like the AI Agents Course), you must:
1. Complete all required modules
2. Build and deploy a working implementation on Hugging Face Spaces
3. Pass the required benchmark thresholds

Check [huggingface.co/learn](https://huggingface.co/learn) for currently active certification deadlines — some cohorts have time-limited certificate programs while others are ongoing.
