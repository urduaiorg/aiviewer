## What It Is

OpenAI's Researcher Access Program provides free API credits to support academic and independent research. Recipients receive:

- Up to **$1,000 in OpenAI API credits**
- Access to OpenAI's full model suite including GPT-4, o1, and other production models
- Credits can be used for any research purpose on the OpenAI platform

## Who It's For

- Academic researchers at universities conducting AI-related research
- Independent researchers working on original studies or publications
- Nonprofit researchers studying AI's effects on society, health, education, or other domains

## Details

| | |
|---|---|
| **Cost** | Free — this is a grant |
| **Grant Amount** | Up to $1,000 in API credits |
| **Review Cycle** | Quarterly (March, June, September, December) |
| **Prerequisites** | Active research project with a clear purpose |
| **Application** | Via the SmApply portal at the URL above |
| **Enrollment** | Rolling with quarterly review windows |

## How to Apply

1. Visit the application portal at the link above
2. Describe your research project, methodology, and how OpenAI's models will be used
3. Submit before the quarterly review window closes
4. Grants are awarded based on research merit and alignment with OpenAI's research interests

Research on AI safety, AI's societal impacts, education, healthcare, and accessibility are areas that have historically received support. Independent researchers without institutional affiliation are eligible.
