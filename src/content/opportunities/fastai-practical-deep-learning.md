## What You'll Learn

fast.ai's flagship course teaches deep learning the way practitioners actually use it — starting with working code, then explaining the theory:

- **Computer Vision** — image classification, object detection, image segmentation
- **Natural Language Processing** — text classification, language model fine-tuning
- **Tabular Data** — neural networks for structured data, embeddings
- **Collaborative Filtering** — recommendation systems
- **Generative AI** — diffusion models, text-to-image, stable diffusion from scratch
- **Foundations** — backpropagation, optimizers, loss functions, activations

The companion textbook — *Practical Deep Learning for Coders* — is also freely available as interactive Jupyter notebooks.

## Who It's For

- Software developers who already know Python and want to learn deep learning properly
- People who find top-down learning more effective than mathematical theory first
- Researchers and practitioners who want to go from working code to deep understanding
- This is **not** a beginner course — it assumes you can read and write Python comfortably

## Why fast.ai

Jeremy Howard (co-founder) helped create the "top-down" pedagogical approach now used by many AI educators. fast.ai alumni have published research at top conferences and built products used by millions. The course's philosophy — that non-PhDs can reach the state of the art — has been validated repeatedly. It's widely considered one of the most rigorous free deep learning resources available.
