OpenAI named it Codex because it was originally a coding tool. That is no longer the most accurate description of what it does.

In April 2026, the updated Codex app shipped with features that have nothing to do with code: computer use that lets it operate your desktop like a user, in-app browsing, image generation, memory that persists across sessions, and more than 90 plugins connecting to services including Atlassian, GitLab, Microsoft, and Slack. GPT-5.5 — OpenAI's newest frontier model — is now the recommended engine for most Codex tasks.

TechCrunch and other outlets have started calling this OpenAI's "super app" play. That framing is not wrong, but it is also not yet quite right. Here is what is actually happening.

## What Codex Now Does

The April 2026 update added several capabilities that push Codex beyond its original category:

**Computer use.** Codex can now operate your desktop — clicking, typing, reading the screen — the way you would. This is the same category of capability that Anthropic's Claude Computer Use introduced, and that OpenAI's own Operator product explored. In Codex, it is aimed at developer tasks: navigating codebases, running tests, interacting with GUIs that do not have APIs.

**In-app browsing.** Codex can browse the web from inside the application. Combined with computer use, this creates a loop where Codex can research a problem, implement a solution, test it, and iterate without you switching context.

**Image generation.** DALL-E integration is now built in, so you can generate visuals, diagrams, or mockups in the same session where you are writing code or working through a task.

**Memory.** Codex now remembers things across sessions — your preferences, project context, how you like to work. For developers who use it daily, this removes the friction of re-explaining context at the start of every conversation.

**90+ plugins.** The new plugin ecosystem covers coding platforms (GitLab, CircleCI, CodeRabbit), productivity (Atlassian, Microsoft), and infrastructure (Neon, Render, Remotion). This is the connective tissue that turns Codex into a platform rather than just a tool.

## What GPT-5.5 Adds

GPT-5.5 is OpenAI's newest frontier model and the default for Codex. The improvements that matter most for knowledge work:

Faster output without meaningfully lower quality. Complex implementations, refactors, and debugging sessions that previously required careful model management now run smoothly on GPT-5.5 as the general-purpose engine.

Better performance on validation tasks — the model is more reliable at checking its own work, which matters most in long agentic loops where errors in early steps compound.

## The "Super App" Question

OpenAI's leadership has publicly framed the long-term vision as combining ChatGPT, Codex, and its AI browser into a single unified product. The idea is one place for coding, research, writing, visual creation, and computer use — rather than separate tools for each.

That vision is coherent. The question is whether Codex in its current form delivers it.

Honest assessment: the pieces are there, but the experience is still fragmented. Computer use works but is not seamless. The plugin ecosystem is large but inconsistent in quality. Memory helps but is not yet sophisticated enough to feel like a genuine running context. And Codex is still primarily used by developers — it has not yet found the broader knowledge-worker audience that the "super app" framing implies.

What OpenAI has built is a credible prototype of the thing they described. The gap between prototype and finished product is where competitors — Claude, Gemini, and an increasingly capable Cursor — have space to operate.

## Who Should Pay Attention

**Developers** who already use Codex for coding work and have not explored its non-coding features are the most obvious group. The browsing, memory, and computer use capabilities are genuinely useful for engineering workflows and available without switching tools.

**Knowledge workers** who are not developers should wait. The super app vision is real but not yet refined enough to replace the specialized tools (Claude for writing, Perplexity for research, Midjourney for images) with a single Codex workflow. Give it six months.

**Teams evaluating AI platforms** should take Codex seriously as a candidate for consolidated tooling. The plugin ecosystem and multi-modal capabilities make it a plausible single-vendor solution for teams that want to simplify.

## How It Compares to Cursor

Cursor and Codex are now clearly competing for the same developer audience, and the distinction has sharpened. Cursor is a code editor that added AI. Codex is an AI product that added code editing. That difference in origin shapes the experience: Cursor feels like a great editor; Codex feels like an AI that can also edit.

Neither framing is wrong. Which one fits your workflow depends on whether you spend most of your time in files (Cursor's strength) or moving between research, planning, implementation, and review (where Codex's breadth helps more).

The SpaceX-Cursor deal — if the acquisition closes — will likely push Cursor toward Codex's breadth. The competition here is accelerating.

**Frequently Asked Questions**

**Is OpenAI Codex free?**
Codex has a free tier with limited usage. Full access to GPT-5.5 and the complete plugin ecosystem requires a ChatGPT Plus or Pro subscription.

**What is the difference between ChatGPT and Codex?**
ChatGPT is OpenAI's general-purpose conversational interface. Codex is the developer-focused application with an integrated code editor, terminal, file management, and developer-specific plugins. GPT-5.5 powers both. OpenAI has indicated they will eventually merge the products into a unified interface.

**Does Codex replace GitHub Copilot?**
They serve different use cases. GitHub Copilot is an inline code completion tool inside your existing editor (VS Code, JetBrains). Codex is a standalone application for broader task completion. They can be used alongside each other.

**What does "computer use" mean in Codex?**
Computer use means Codex can see your screen and control your mouse and keyboard to perform tasks on your behalf. It can navigate applications, fill in forms, and interact with software that does not have an API, the same way a remote assistant would.
