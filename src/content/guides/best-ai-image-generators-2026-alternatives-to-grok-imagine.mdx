Choose an AI image workflow by its ability to produce an asset you can use. Write the brief first, check the output against it and try one meaningful revision. An attractive sample that contains the wrong event details still fails a poster task.

## Build a brief with an answer key

This is a **fictional teaching exercise** for a community pottery workshop. It is not a real event announcement or a product test.

| Field | Required content |
|---|---|
| Title | Clay Workshop |
| Date | Saturday 14 November |
| Time | 10:00–12:00 |
| Location | River Room |
| Price | Free |
| Image subject | One blue ceramic mug |
| Format | Square poster, readable on a phone |

The table is your answer key. Keep it beside the generated image so you can check every detail. A model should not invent a registration address, organizer endorsement or venue logo.

An example brief is:

> Create a square poster concept for a fictional pottery workshop. Feature one blue ceramic mug on a light background. Reserve clear space for a title and four short event details. Use a calm, simple composition suitable for a small phone screen.

For task-specific prompting help, consult the documentation for your chosen tool, such as [Adobe's Firefly prompt guidance](https://helpx.adobe.com/firefly/web/work-with-images/generate-images/writing-effective-text-prompts.html). Documentation can explain controls and prompting approaches; it cannot establish that a tool will win this exercise.

## Decide where the exact text will be placed

You can ask an image model to render the wording, or generate the illustration and add text in a layout editor. Test the workflow you intend to use. If one candidate includes a layout-editing step and the other does not, record the extra work.

For the exercise, an illustration with separately editable text is a useful option because you can correct a date without regenerating the mug. That is a workflow choice, not a claim that a particular provider produces better images.

## Inspect a deliberately flawed result

Imagine a poster containing these details: “Clay Workshops,” “Sunday 14 November,” “10:00–12:00,” “River Room,” and “Free entry — materials CAD 15.” This is an authored description of a flawed example. No image generator was observed producing it.

Three corrections are required:

1. Restore the exact title, “Clay Workshop.”
2. Restore “Saturday” from the answer key.
3. Remove the invented materials charge. The input only says “Free.”

Do not excuse those errors because the colors look good. Also check that the image contains one blue mug and that its shape is usable for the intended design. Keep essential factual checks separate from aesthetic preference.

## Try a revision that matters

After selecting an acceptable starting image, change the workshop time to 13:00–15:00. Keep everything else the same. Record whether the workflow preserves the title, date, location, price and composition.

The acceptance check is specific: only the time should change. If a new image also changes the mug color or adds another event detail, record the regression and the work needed to fix it. This exercise reveals more about ongoing editing than a single attractive first output.

Use the same revision brief and attempt budget for each workflow. Save the prompt, original output, revised output and any manual edits. Label those records with the tool, model where visible, account conditions and date.

## Use a decision worksheet

| Question | Record for each workflow |
|---|---|
| Did it meet the essential brief? | Pass or fail, with the failed detail |
| Was every word correct? | Exact discrepancies against the answer key |
| Did the revision preserve other details? | Unwanted changes, if any |
| What did finishing require? | Manual edits and active review time |
| What did the trial cost? | Actual credits or charges, with the billing context |
| Can you use the result as intended? | Applicable terms checked; unresolved questions |

Choose among the workflows that satisfy your essential requirements. You may prefer one composition, but explain that preference rather than assigning an unsupported universal quality score. A low first-attempt cost also does not account for multiple retries or manual repair.

## Your next exercise

Change the fictional workshop to an event you are allowed to publish. Verify the real details with its organizer before using them. Repeat the text check after exporting and view the final asset at the size your readers will see.
